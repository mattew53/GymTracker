GYM TRACKER — APP iOS PERSONALE

Questa è una vera app iOS nativa che contiene il Gym Tracker. Non apre Safari.

Il progetto è pensato per essere compilato gratuitamente su un runner macOS di GitHub Actions e poi installato su un iPhone tramite sideloading da Windows.

1. Crea un repository GitHub personale e carica questa cartella.
2. Apri Actions -> Build Gym Tracker iOS -> Run workflow.
3. Quando termina, scarica l'artefatto GymTracker-IPA.
4. Usa un tool Windows compatibile per firmare/installare l'IPA con il tuo Apple ID.

Nota: il metodo di sideloading con Apple ID gratuito ha limiti Apple e richiede periodicamente un refresh dell'app.
